# FocusPulse - Offline Pomodoro & Ambient Audio

Distraction-free focus timer with ambient sound generator, offline session logging, and productivity analytics.

## Features
- Customizable work/break intervals
- Offline ambient sound generator
- Daily focus analytics & streaks
- Background notification sync

## Tech Stack
- **Vite** & **React 18** with TypeScript
- **Tailwind CSS** for responsive mobile-first styling
- **Workbox / Vite PWA Plugin** for offline caching & service worker lifecycle

## Development
```bash
npm install
npm run dev
```
